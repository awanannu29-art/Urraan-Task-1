# Urraan-Task-1
# URRAAN HTML Layout Task

## Introduction

This project is created as part of the URRAAN Training Program.

The purpose of this task is to create a webpage layout using HTML semantic tags and CSS. The layout is designed according to the provided image.

## Project Structure

The project contains two files:
index.html
style.css

## HTML Tags Used

In this project, I used the following HTML tags:

- `<header>` for the top section
- `<nav>` for the navigation section
- `<main>` for the main content area
- `<section>` for the two content sections
- `<aside>` for the sidebar
- `<footer>` for the bottom section

## Important Rule

I did not use any `<div>` tags in this project.

The layout was created using semantic HTML tags as required in the task.

## CSS

CSS Grid is used to arrange the sections of the webpage.

The webpage contains:

- A header at the top
- A navigation area below the header
- Two sections on the left side
- A sidebar on the right side
- A footer at the bottom

## How to Run the Project

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open the `index.html` file.
4. Run the file using Live Server or open it in a web browser.

## Learning Outcome

Through this task, I learned how to:

- Use semantic HTML tags
- Create a webpage layout without using `<div>`
- Use CSS Grid for layout design
- Connect an HTML file with a CSS file
